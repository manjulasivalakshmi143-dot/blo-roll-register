# BLO Roll Register

Free web app for Booth Level Officers. Import your part's electoral roll (PDF, Excel/CSV or photos), then mark mobile updated, Aadhaar linked (Yes/No only), ASD, voter slips and Form 6/7/8 in the field. When a new SSR/SIR roll comes, import it again to see new, removed and corrected voters.

- Each BLO signs in with their own email and password; their list is private to them.
- Works on the phone, saves a copy on the device, and can download a full Excel backup.
- Roll PDFs are read on the phone itself; no voter data is stored in this repository.
